OBJETIVOS FUNCIONALES:

1) BASE DE DATOS (Supabase) - crear/usar estas tablas:
A) diet_rates:
- id uuid pk default gen_random_uuid()
- user_id uuid not null references auth.users(id)
- scope text not null (NACIONAL | INTERNACIONAL)
- percent int not null (100 | 60 | 30)
- amount_eur numeric not null
Unique: (user_id, scope, percent)

B) day_extras:
- id uuid pk
- user_id uuid not null
- kind text not null (SAB | DOM | FEST)
- amount_eur numeric not null
Unique: (user_id, kind)

C) holidays:
- id uuid pk
- user_id uuid not null
- date date not null
- name text
Unique: (user_id, date)

D) journeys:
- id uuid pk
- user_id uuid not null
- start_at timestamptz not null
- end_at timestamptz not null
- start_place text
- end_place text
- travel_type text (NAC | INTL | REG_INTL | NAC_INTL | NAC_REG)
- pernocta boolean default false
- diet_mode text (AUTO | MANUAL)
- diet_percent int (100|60|30) nullable
- manual_scope text (NACIONAL|INTERNACIONAL) nullable
- special_day text (AUTO|SAB|DOM|FEST)
- driving_hours_override numeric nullable
- diet_base_eur numeric not null default 0
- extra_day_eur numeric not null default 0
- diet_total_eur numeric not null default 0

Reglas de cálculo:
A) Resolver end_at:
- start_at ya guardado.
- si el usuario elige fecha fin distinta, usarla.
- si fecha fin = start_at date y hora fin < hora inicio -> end_at = end_at + 1 day.

B) Calcular base diet (diet_base_eur):
- Si diet_mode = MANUAL:
  - base = lookup diet_rates por (manual_scope, diet_percent)
- Si diet_mode = AUTO:
  - travel_type:
    * NAC:
        - si pernocta=true -> NACIONAL 100
        - si pernocta=false -> NACIONAL 60
    * INTL:
        - usar INTERNACIONAL con el % seleccionado (si no hay seleccionado, default 100)
    * REG_INTL:
        - INTERNACIONAL 60
    * NAC_INTL:
        - NACIONAL 60 + INTERNACIONAL 60 (sumar dos rates)
    * NAC_REG:
        - si pernocta=true -> NACIONAL 100
        - si pernocta=false -> NACIONAL 60

C) Calcular extra_day_eur:
- Si special_day = SAB/DOM/FEST: lookup day_extras.kind y sumar.
- Si special_day = AUTO:
   1) si end_date está en holidays -> FEST
   2) else si end_date es domingo -> DOM
   3) else si end_date es sábado -> SAB
   4) else -> 0

D) diet_total_eur = diet_base_eur + extra_day_eur

Guardar estos valores en journeys.
